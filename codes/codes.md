## Codes
This folder contains the robot control source code used for the WRO 2025 challenges. Two primary scripts are included:

- **Obstacle Challenge:** `codes/obstacle-challenge-code.py` — implementation and control logic used for the Obstacle Challenge (sensor handling, obstacle detection, and navigation routines).
- **Open Challenge:** `codes/open-challenge-code.py` — control and task logic for the Open Challenge (line following, object manipulation, or challenge-specific tasks).

Both files include comments and configuration sections for pin assignments and sensor calibration. Run them on the robot's onboard computer or microcontroller environment as documented in the project README.
